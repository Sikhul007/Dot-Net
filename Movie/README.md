# Movie Database API

## Overview

The Movie Database API is a backend service built using the .NET Framework. It provides endpoints for managing movie records and user movie lists. The project currently supports the following features:

## Features Implemented

- **Add, View, and Delete Movie Records**

  - API endpoints to add new movies to the database.
  - Retrieve movie records in JSON format.
  - Delete movie records via API calls.

- **Display Movie Details**

  - API provides movie details including title, director, genre, and release date.

- **Search by movie Title or Director**

  - User can Search movies by title or director for showing the details or filtered movie.

- **Favorite Movies List**

  - Users can mark movies as favorites and retrieve their favorite list.

- **Movie Watchlist**
  - Users can add movies to their watchlist via API endpoints.
